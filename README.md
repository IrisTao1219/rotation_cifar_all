## 数据与模型

| 数据 | 原图数量 | 已包含的文件 |
|---|---:|---|
| 训练集 | 40,000 | `rotation_cifar/data/train.npz` |
| 开发集 | 5,000 | `rotation_cifar/data/dev.npz` |
| 独立确认集 | 5,000 | `rotation_cifar/data/confirm.npz` |
| 官方测试集 | 10,000 | `官方测试_2026-10-11/data/official_test.npz` |
| 原始固定版本镜像 | 训练部分 50,000；测试部分 10,000 | 两个数据目录中的 `train.parquet`、`test.parquet` |

训练、开发、确认均来自 CIFAR-10 官方训练部分，按原图先划分，再生成旋转视图。模型使用 0°、90°、180°、270°四个方向。所有 NPZ 都已准备好，训练和测试无需重新下载数据。

主对照为 `aug4_large`，模块为 `pool_max_large`，最终使用 seed 1、2、3，均训练 80 轮。六份主模型位于 `rotation_cifar/runs/<模式>_s<种子>_e80/best.pt`。其余权重与日志保留为早期对照、消融和未采用方案的记录，不能全部视为有效改进。

## 当前结果与文档版本

官方测试的三种子平均准确率为 **72.96% → 74.48%，提升 1.52 个百分点**；宏平均 F1 为 **72.81% → 74.31%**。准确率配对收益的 95% bootstrap 区间为 +0.79～+2.22 个百分点。主对照的简单融合方式由开发集预先确定，未根据官方测试挑选。

此前独立确认集的准确率为 73.56% → 75.41%，提升 1.85 个百分点。两组数字来自不同数据集，报告时应同时写清评价集合，不能互相替代。

共享编码与逐维最大聚合的核心思想借鉴已有 TI-pooling。当前贡献是课程基线上的模块接入、适配和验证，不宣称首次提出这一聚合算法。

本次保留当前 Word 的内容与格式，并据此同步 PDF、Markdown；初稿三种格式单独保存在“历史报告”。原实验快照与历史说明逐字节保留，其中“官方测试尚未使用”等文字描述的是当时的状态。当前官方测试已经完成，最新结果以本目录所链接的官方测试报告为准。

## 整合与核验

整合时重新读取了服务器项目的文件清单，178 个服务器文件均与本地已有文件的 SHA256 相同。原训练快照的 150 个文件、官方测试补充的 30 个文件均完整保留；本地新增的说明、网页和报告也已收录。

`归档记录/本次整合来源.json` 说明各来源与版本处理方式，`归档记录/本次整合核验.json` 记录文件、数据和报告一致性检查。原有校验清单仅对应历史归档；本次交付以根目录的 `文件清单SHA256.json` 和压缩包旁的 `.zip.sha256` 为准。

本次只做整合与校验，没有重新训练或根据测试分数调整方法。训练与模型推理需要 NVIDIA CUDA 环境，推荐单张空闲 4090；阅读报告、打开网页和校验文件不需要 GPU。
